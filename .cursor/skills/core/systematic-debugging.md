# Systematic Debugging

## 4-фазный поиск багов

### Фаза 1: Воспроизведение

1. Опиши проблему точно
2. Найди минимальный путь воспроизведения
3. Зафиксируй условия (платформа, данные, сеть)

```dart
// Добавь логирование для воспроизведения
debugPrint('Загрузка станции: $stationId');
debugPrint('URL: $streamUrl');
```

### Фаза 2: Локализация

1. Используй бинарный поиск по коду
2. Добавляй `debugPrint` на границах модулей
3. Проверь данные на входе/выходе функции

```dart
void loadStation(String id) {
  debugPrint('[LOAD] Начало: $id');
  // ...
  debugPrint('[LOAD] Данные получены: $data');
  // ...
  debugPrint('[LOAD] Завершено');
}
```

### Фаза 3: Анализ

1. Проверь гипотезы по очереди
2. Используй точку останова (debugger)
3. Сравни с ожидаемым поведением

```bash
# Запусти с подробным логом
flutter run --verbose

# Проверь логи Firebase
firebase database:get /
```

### Фаза 4: Исправление

1. Напиши тест на баг (должен падать)
2. Исправь код
3. Проверь что тест проходит
4. Запусти все тесты

```dart
test('должен_обрабатывать_пустой_список_станций', () async {
  // Тест на баг
});
```

## Инструменты

- `debugPrint()` — Логирование
- `flutter run --verbose` — Подробный лог
- DevTools — Профилирование
- `print()` — Только для отладки (удаляй после)
