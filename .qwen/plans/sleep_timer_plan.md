# 📋 Sleep Timer Feature Plan

**Статус:** В разработке  
**Приоритет:** Средний  
**Оценка:** 110 минут  
**Начало:** 2026-02-28

---

## 📖 Описание

Добавить таймер сна для автоматической остановки воспроизведения через заданное время.

---

## ✅ Требования

### Функциональные
- [ ] Выбор времени из пресетов (15, 30, 60, 90 минут)
- [ ] Кастомное время через picker
- [ ] Обратный отсчёт в реальном времени
- [ ] Авто-остановка плеера по истечении
- [ ] Сохранение состояния при перезапуске
- [ ] Отмена таймера в любой момент

### Нефункциональные
- [ ] Работать в фоне
- [ ] Минимальное потребление батареи
- [ ] Плавная анимация отсчёта
- [ ] Локализация (RU, EN)
