# Изображения для радиостанций

В этой папке должны находиться изображения для радиостанций:

- `viktoria.jpg` - изображение для радиостанции "Виктория"
- `tetim.jpg` - изображение для радиостанции "Тэтим"
- `ir_radio.jpg` - изображение для радиостанции "IR Radio"
- `europa_plus.jpg` - изображение для радиостанции "Европа Плюс"

Эти изображения используются в приложении как обложки для радиостанций.
