# Полное решение проблемы CORS и запуска приложения

## Проблема
Приложение radio_v2 сталкивалось с проблемой CORS при попытке запросить данные с внешних API, таких как `horo.mail.ru`. 

## Решение

### 1. Прокси-сервер
Создан прокси-сервер на Node.js (server.js), который запускается на порту 5000 и обеспечивает безопасный доступ к внешним API, обходя ограничения CORS.

### 2. Автоматизированные скрипты запуска
Созданы скрипты для автоматического запуска обоих сервисов:
- `run_app.bat` для Windows
- `run_app.sh` для Linux/Mac

## Использование

### Вручную:
1. Запустите прокси-сервер: `node server.js`
2. Запустите Flutter-приложение: `flutter run -d chrome`

### Автоматически:
1. Запустите соответствующий скрипт: `run_app.bat` или `./run_app.sh`

## Проверка работоспособности
Используйте скрипт `check_status.bat` для проверки состояния обоих сервисов.

## Архитектура
- Прокси-сервер: http://localhost:5000
- Flutter-приложение: http://localhost:[случайный_порт]
- Приложение использует прокси-сервер для безопасного получения данных с внешних API
