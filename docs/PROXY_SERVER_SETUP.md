# Инструкция по запуску приложения с прокси-сервером

## Проблема CORS

При попытке запросить данные с `horo.mail.ru` из веб-браузера возникает ошибка CORS (Cross-Origin Resource Sharing), 
поскольку браузеры блокируют запросы между разными доменами для обеспечения безопасности.

## Решение

Для решения проблемы создан прокси-сервер на Node.js, который перенаправляет запросы к внешним API, 
обходя ограничения CORS.

## Структура решения

### 1. Прокси-сервер (server.js)
- Расположение: `g:\radio_v2\server.js`
- Запускается на порту 5000
- Обеспечивает маршруты для безопасного получения данных с внешних API
- Реализует проверку доверенных доменов для безопасности

### 2. Обновленный клиентский код
- Сервис `HoroscopeService` теперь использует URL прокси-сервера
- Вместо `https://horo.mail.ru` используется `http://localhost:5000/api`

## Запуск приложения

### Шаг 1: Запуск прокси-сервера
```bash
cd g:\radio_v2
node server.js
```

Сервер будет доступен по адресу: `http://localhost:5000`

### Шаг 2: Запуск Flutter-приложения
```bash
cd g:\radio_v2
flutter run -d chrome
```

Приложение будет доступно по случайному порту (обычно в диапазоне 3000-9000).

Альтернативно, вы можете использовать скрипт запуска:
```bash
run_app.bat
```

Этот скрипт автоматически запустит и прокси-сервер, и Flutter-приложение.

## Доступные маршруты прокси-сервера

- `GET /api/horo/:category/:sign` - Получение гороскопа по категории и знаку зодиака
- `GET /api/horo-full/:sign/:period` - Получение полной HTML-страницы гороскопа
- `GET /api/proxy?url=<url>` - Универсальный прокси для доверенных доменов
- `POST /api/proxy` - POST-запросы через прокси
- `GET /api/status` - Проверка состояния сервера

## Безопасность

Сервер проверяет, что запрашиваемые домены находятся в списке доверенных:
- `horo.mail.ru`
- `api.openweathermap.org`
- `ysia.ru`
- `api.telegram.org`

## Остановка приложения

Для остановки прокси-сервера:
```bash
taskkill /F /T /PID <номер_процесса_сервера>
```

Для остановки Flutter-приложения просто закройте терминал или нажмите `q` в терминале, где запущено приложение.
