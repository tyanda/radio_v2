# Решение проблемы с запуском веб-версии приложения

## Проблема

При попытке запустить веб-версию Flutter-приложения возникала ошибка:

```
Error while trying to load an asset: Flutter Web engine failed to fetch "assets/.env". HTTP request succeeded, but the server responded with HTTP status 404.
DartError: Instance of 'FileNotFoundError'
```

Это происходило потому, что веб-браузер не может получить доступ к локальным файлам в корне проекта из соображений безопасности.

## Решение

Мы решили проблему, создав отдельные файлы конфигурации для веб- и нативных платформ:

1. `lib/core/config_web.dart` - для веб-версии, использует значения по умолчанию
2. `lib/core/config_native.dart` - для нативных версий, загружает переменные из .env файла
3. `lib/core/config.dart` - файл экспорта, который выбирает нужный файл в зависимости от платформы

### Используемые файлы:

- `lib/core/config.dart` - файл экспорта
- `lib/core/config_web.dart` - конфигурация для веба
- `lib/core/config_native.dart` - конфигурация для нативных платформ
- `lib/main.dart` - обновлен для использования новой системы конфигурации
- `lib/firebase_options.dart` - обновлен для использования значений из конфигурации
- `lib/services/rss_service.dart` - обновлен для использования значений из конфигурации
- `lib/features/weather/data/weather_service.dart` - обновлен для использования значений из конфигурации

## Результат

Теперь веб-версия приложения запускается без ошибок, используя значения по умолчанию, а нативные версии продолжают использовать переменные из .env файла.
